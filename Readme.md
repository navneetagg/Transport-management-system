# Industrial Transport & Fleet Logistics Management Workspace

A high-performance, responsive MERN stack infrastructure built from scratch to streamline plant-level logistics, track industrial machinery vehicle availability, and control shipment lifecycle transitions.

## 🚀 Key Features
- **Live Infrastructure Telemetry**: Real-time summary cards computing Scheduled, In Transit, and Successful Deliveries directly from the database streams.
- **Transactional State Workflows**: One-click status transitions (`Scheduled` -> `In Transit` -> `Delivered`) that automatically alter the linked transport vehicle's structural availability.
- **Fleet Deployment Registry**: Interactive input forms to enroll heavy machinery transport loaders and freight drivers.
- **Modern Minimalist UI**: Built using React, Tailwind CSS (v4), and Lucide React icons with a complete responsive dark sidebar panel configuration.

## 🛠️ Tech Stack & Architecture
- **Frontend**: React (Vite), Tailwind CSS (v4), Lucide React
- **Backend**: Node.js, Express.js (CommonJS modular architecture)
- **Database**: MongoDB via Mongoose Object Modeling
